# Project Proposal: DeepCoach-RL

**Event-Driven Hierarchical Reinforcement Learning for Tactical Football Management**

---

## 1. Executive Summary & Problem Statement

Standard approaches to sports AI in physics-based environments like Google Research Football (GRF) focus heavily on micro-agent control. In these setups, deep neural networks dictate frame-by-frame low-level mechanics (e.g., passing, shooting, running) at 10 Hz. Across a 90-minute match (54,000 engine steps), this creates severe temporal credit assignment problems, requiring hundreds of millions of environment steps and massive multi-GPU clusters to achieve policy convergence.

**DeepCoach-RL** re-architects sports management as an **Event-Driven Semi-Markov Decision Process (SMDP)**. Instead of controlling continuous physical movement, a central neural coach emits high-level macro-tactical directives—such as altering structural formations, adjusting defensive engagement heights, tweaking pressing intensity, and executing substitutions. Low-level player mechanics are handled natively by the engine's physics engine or low-level heuristics.

By stepping the policy exclusively at macro-intervals (every 5 match minutes) or upon critical match events (goals, red cards, or severe fatigue), the episode horizon drops from 54,000 steps to **15–20 decision nodes**. This allows a pure PyTorch RL agent to discover complex, adaptive tactical strategies in a few hours on a single GPU.

### Key Technical Innovations

1. **Semi-Markov Decision Process (SMDP) Temporal Compression:** Shrinks temporal credit assignment distance by $3,000\times$, linking late-game outcomes directly to intermediate macro-tactical interventions.


2. **Action-Masked Multi-Discrete Control:** Incorporates `MaskablePPO` to dynamically enforce real-world sports constraints (e.g., substitution limits, player eligibility) directly within the policy's logit distribution.


3. **Expected Goals ($\text{xG}$) Reward Shaping:** Evaluates intermediate performance using net shot-quality generation ($\Delta \text{xG}$) rather than raw goals, reducing stochastic variance in training signals.


4. **Fictitious Self-Play League Training:** Trains the agent against a dynamic league pool of its historical checkpoints to prevent single-strategy exploits and build true tactical resilience.

## 3. Mathematical MDP Formulation

### State Space ($S_t \in \mathbb{R}^{28}$)

Extracted from the GRF environment telemetry vector upon each macro-trigger:

* **Match Situation ($3$ features):** Score differential ($\Delta G \in [-10, 10]$), normalized remaining match time ($T_{\text{rem}} \in [0, 1]$), cumulative Expected Goals differential ($\text{xG}_{\text{diff}} \in [-5.0, 5.0]$).


* **Squad Physical Condition ($11$ features):** Vector of individual stamina/fatigue levels for active players ($P_i \in [0, 1]$).


* **Active Formations ($10$ features):** One-hot categorical vectors representing the team's active system ($\mathbf{F}_{\text{agent}} \in \{0, 1\}^5$) versus the opponent's active system ($\mathbf{F}_{\text{opp}} \in \{0, 1\}^5$).


* **Field Spatial Control ($3$ features):** Share of ball possession held in the defensive, middle, and attacking thirds over the preceding 5-minute interval.
* **Disciplinary Status ($1$ feature):** Active yellow/red card penalty count accumulated by the team.



### Multi-Discrete Action Space ($A_t$)

1. **Formation ($A_{\text{form}} \in \{0..4\}$):** $0 \to 4\text{-}3\text{-}3$, $1 \to 4\text{-}2\text{-}3\text{-}1$, $2 \to 3\text{-}5\text{-}2$, $3 \to 5\text{-}4\text{-}1$, $4 \to 3\text{-}4\text{-}3$.


2. **Defensive Line Height ($A_{\text{line}} \in \{0..2\}$):** $0 \to \text{Low Block}$, $1 \to \text{Mid Line}$, $2 \to \text{High Offside Trap}$.
3. **Pressing Intensity ($A_{\text{press}} \in \{0..2\}$):** $0 \to \text{Containment}$, $1 \to \text{Balanced}$, $2 \to \text{Gegenpress}$.


4. **Substitutions ($A_{\text{sub}} \in \{0..5\}$):** $0 \to \text{No Sub}$, $1..5 \to \text{Swap most fatigued starter with Bench Player } 1..5$.



### Reward Function ($R_t$)

$$R_t = R_{\text{terminal}} + \alpha \cdot \Delta \text{xG}_t - \beta \sum_{i=1}^{11} \max(0, 0.35 - P_{i, t}) - \gamma \cdot \mathbb{I}(A_t \neq A_{t-1})$$

Where:

* $R_{\text{terminal}} = +1.0$ (Win), $0.0$ (Draw), $-1.0$ (Loss) at minute 90.


* $\Delta \text{xG}_t$: Net change in Expected Goals created minus conceded during the 5-minute window ($\alpha = 0.2$).


* $\beta = 0.5$: Penalizes allowing any player's stamina to drop below $35\%$, forcing timely substitutions.


* $\gamma = 0.05$: Friction penalty applied if tactics change every single step, promoting strategic stability.

## 3. Core Module Implementations

### A. Environment Wrapper (`src/env_wrapper.py`)

```python
import gymnasium as gym
from gymnasium import spaces
import numpy as np
import gfootball.env as football_env

class SMDPFootballEnv(gym.Env):
    """
    Event-Driven Semi-Markov Decision Process Wrapper around Google Research Football.
    Steps physics for 5-minute macro intervals or critical game events.
    """
    def __init__(self, render=False):
        super().__init__()
        # Initialize underlying GRF physics engine
        self.grf_env = football_env.create_environment(
            env_name="11_vs_11_easy_stochastic",
            stacked=False,
            representation="raw",
            rewards="scoring",
            write_goal_dumps=False,
            write_full_episode_dumps=False,
            render=render
        )
        
        # Multi-Discrete Action Space: [Formation, LineHeight, Pressing, Substitution]
        self.action_space = spaces.MultiDiscrete([5, 3, 3, 6])
        
        # State Space: Vector S_t in R^28
        self.observation_space = spaces.Box(
            low=-10.0, high=10.0, shape=(28,), dtype=np.float32
        )
        
        self.subs_used = 0
        self.max_subs = 5
        self.last_action = np.zeros(4, dtype=int)
        self.prev_xg_diff = 0.0

    def get_action_mask(self) -> np.ndarray:
        """
        Generates dynamic binary masks for MaskablePPO.
        Prevents illegal substitutions when sub quota (5) is exhausted.
        """
        # Mask arrays for each multi-discrete dimension
        mask = [
            np.ones(5, dtype=bool),  # Formations (all 5 valid)
            np.ones(3, dtype=bool),  # Line Height (all 3 valid)
            np.ones(3, dtype=bool),  # Pressing (all 3 valid)
            np.ones(6, dtype=bool)   # Substitutions
        ]
        
        # If substitution cap reached, mask out sub options 1..5
        if self.subs_used >= self.max_subs:
            mask[3][1:] = False
            
        return mask

    def _extract_state(self, obs) -> np.ndarray:
        """Parses raw GRF dictionary into normalized 28-dimensional state vector."""
        raw = obs[0] if isinstance(obs, list) else obs
        
        # Extract features
        score_diff = float(raw['score'][0] - raw['score'][1])
        time_rem = float(1500 - raw['steps_completed']) / 1500.0  # 1500 steps = 90 mins
        stamina = np.array(raw['right_team_tired_factor'][:11], dtype=np.float32) # Normalized 0..1
        
        # Placeholder for calculated xG difference
        xg_diff = self.prev_xg_diff
        
        # Possession in 3 zones (Defensive, Mid, Attack)
        ball_x = raw['ball'][0] # -1.0 to 1.0
        poss_def = 1.0 if ball_x < -0.33 else 0.0
        poss_mid = 1.0 if -0.33 <= ball_x <= 0.33 else 0.0
        poss_att = 1.0 if ball_x > 0.33 else 0.0
        
        cards = float(np.sum(raw['left_team_yellow_card']))
        
        # Formations (One-Hot Encoded 5-dim vectors)
        agent_form = np.zeros(5, dtype=np.float32)
        agent_form[self.last_action[0]] = 1.0
        
        opp_form = np.zeros(5, dtype=np.float32)
        opp_form[0] = 1.0  # Default baseline opponent system
        
        state_vec = np.hstack([
            [score_diff, time_rem, xg_diff],
            stamina,
            agent_form,
            opp_form,
            [poss_def, poss_mid, poss_att],
            [cards]
        ]).astype(np.float32)
        
        return state_vec

    def reset(self, seed=None, options=None):
        raw_obs = self.grf_env.reset()
        self.subs_used = 0
        self.last_action = np.zeros(4, dtype=int)
        self.prev_xg_diff = 0.0
        state = self._extract_state(raw_obs)
        return state, {}

    def step(self, action):
        # Update substitution tracking if sub executed
        if action[3] > 0 and self.subs_used < self.max_subs:
            self.subs_used += 1
            
        # Unroll physics engine for 83 steps (~5 match minutes in GRF)
        macro_steps = 83
        accumulated_reward = 0.0
        done = False
        
        for _ in range(macro_steps):
            raw_obs, reward, done, info = self.grf_env.step(action)
            accumulated_reward += reward
            if done:
                break
                
        # Calculate State & Composite SMDP Reward
        state = self._extract_state(raw_obs)
        
        # Compute Reward
        stamina_pen = np.sum(np.maximum(0.0, 0.35 - state[3:14]))
        tactical_friction = 0.05 if np.any(action != self.last_action) else 0.0
        
        smdp_reward = accumulated_reward - (0.5 * stamina_pen) - tactical_friction
        self.last_action = action
        
        return state, smdp_reward, done, False, {}

```

### B. Training Script with Self-Play Checkpointing (`train.py`)

```python
import os
import torch
from sb3_contrib import MaskablePPO
from sb3_contrib.common.maskable.policies import MaskableActorCriticPolicy
from src.env_wrapper import SMDPFootballEnv

def train_deepcoach():
    checkpoint_dir = "./checkpoints/"
    os.makedirs(checkpoint_dir, exist_ok=True)
    
    # Instantiate Environment
    env = SMDPFootballEnv(render=False)
    
    # Initialize MaskablePPO
    model = MaskablePPO(
        policy=MaskableActorCriticPolicy,
        env=env,
        learning_rate=3e-4,
        n_steps=128,              # Macro-steps per update batch
        batch_size=32,
        n_epochs=10,
        gamma=0.99,
        gae_lambda=0.95,
        clip_range=0.2,
        ent_coef=0.01,
        verbose=1,
        tensorboard_log="./tb_logs/"
    )
    
    print("--- Starting DeepCoach-RL SMDP Training ---")
    total_timesteps = 100_000  # Equivalent to ~5,000 full matches
    
    # Training Loop with Checkpointing for Self-Play League Pool
    save_interval = 10_000
    for step in range(0, total_timesteps, save_interval):
        model.learn(total_timesteps=save_interval, reset_num_timesteps=False)
        checkpoint_path = os.path.join(checkpoint_dir, f"deepcoach_step_{step + save_interval}.zip")
        model.save(checkpoint_path)
        print(f"[CHECKPOINT] Saved League Checkpoint: {checkpoint_path}")

if __name__ == "__main__":
    train_deepcoach()

```
